INTRODUCTION

백엔드 개발 과정에서 Amazon RDS for MySQL 기반 성적 관리 시스템을 설계하고, Smart Ring Mobile App과 관제센터 사이의 중계 서버에서 MongoDB를 처리 기록 보관 용도로 활용한 경험이 있습니다. 서비스 데이터를 안정적으로 저장하고 효율적으로 활용하는 과정에 관심을 가지면서 Oracle DBA를 목표로 데이터베이스 운영 분야의 전문성을 준비하고 있습니다.

5개월간의 Oracle DBA 교육과정을 통해 Oracle Database 구조, SQL·PL/SQL, 사용자 및 권한 관리, 백업·복구, 성능 분석과 장애 대응을 학습할 예정입니다. 수료 후에는 실제로 수행한 실습과 프로젝트의 환경, 분석 과정, 개선 결과를 이력서와 GitHub에 구체적으로 기록하겠습니다.

Linux·AWS 환경의 백엔드 개발 경험을 바탕으로 운영 환경을 이해하고, 장애 원인을 논리적으로 분석하며 안정적인 데이터 서비스를 지원하는 DBA로 성장하고자 합니다.
